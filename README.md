# architecture-propdevelopment

# Задание 1
Классификация данных выполнена по уровню чувствительности и критичности для бизнеса в логике ISO/IEC 27001/27002: от публичных до секретных данных. Для каждого типа данных определён наиболее актуальный риск с качественной оценкой влияния по шкале «незначительный — значительный — критический». При оценке учитывались текущие проблемы архитектуры PropDevelopment: отсутствие системного контроля потоков данных, несколько точек регистрации клиента, слабый контроль партнёрских API, риск нарушения разграничения доступа и высокая чувствительность персональных, финансовых и интеграционных данных.
