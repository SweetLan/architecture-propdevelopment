# Проверочный лист безопасности для бизнес-систем PropDevelopment

## Область проверки
Проверка охватывает бизнес-системы PropDevelopment:
- клиентские сервисы продаж: витрина продаж, client-tour-app, client-mart-app, client-crm-app, client-mart-estate-app;
- сервисы для собственников: tenant-core-app, CRM собственников;
- системы идентификации и доступа: auth-service-1, Active Directory;
- финансовые системы: accountant-service-1;
- системы данных: хранилище данных, DWH, BI;
- внешние интеграции: госреестры, платёжная система, поставщики ресурсов ЖКХ, API партнёров.

## Шкала заполнения
- **Да** — требование явно выполняется
- **Нет** — требование не выполняется
- **Частично** — реализовано неполно или не для всех систем
- **Неизвестно** — в исходных данных нет достаточной информации
